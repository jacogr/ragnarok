# Bounded pages of original complete logical state

Scope: unchanged pinned state/proof formats, complete-map Merklization, original logical provenance
and managed graph leases. Whole-map proof export need not fit one request's key/wire/hash allowance.
`planLogicalProofPages` freezes the original complete sorted selector and positive page width under
separate whole-selector and worst-page copy policies. Each immutable page retains its exact original
logical source, posterior root, ordinal and contiguous range. No mutable cursor, raw namespace inversion,
caller-substituted source, hashing or worker launch occurs during planning/page capture. Empty maps
have one empty page; saturated caller limits narrow only after admission. Page quotas account for
input, retained keys and the pinned sort buffer before allocation.

The Services planning adapter enforces preparation/proof/publication exclusion. Outside all native
leases, capture a page and retain its source/keys in outer locals before existing `beginLogicalProof`.
Keep all aliases untouched through actual matching collection or joined close. Done, cancellation and
wrong-ticket collection do not release ownership. Independent existing query policies still admit the
whole map/view and each page's proof work. Pages bound a request's keys, not the retained complete source.

Authenticate each detached response with its exact immutable page selector and independently chosen
root. Existing `mergeProofViews` coalesces consistent repeated facts under one root; arrival order
confers no authority. Missing pages remain unknown witnesses. Neither page counts nor range metadata
certify completeness: only `importProofState` rebuilding the full candidate and matching the expected
root permits complete-map ownership. Proper prefixes/subsets expose no complete snapshot. Existing
wire framing, checkpoint formats, root trust, schema validation and canonical adoption are unchanged.

Native qualification uses a genuine collected uninstalled logical child, reverse-order managed pages,
direct/managed byte equality, wrong-ticket lease retention, repeated delivery, omitted-page unknown
facts, incomplete-prefix refusal, full expected-root reconstruction, every physical value, independently
supplied schema/raw-key qualification and code availability. Default/one-short/saturated page policies,
nested query failures, privacy and all three Services lease guards are checked. Tests retain explicit
source-owned native profiles; they are implemented-scope evidence, not independent current-schema
STF goldens or producer mutation certificates.
