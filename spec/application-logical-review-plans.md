Current and logical review can admit all targeted work before content execution. Core
`planCurrentReview` freezes the original qualified current serialization, its internally selected
complete parameter rates and the existing account review admission/reports. `executeCurrentReview`
accepts only that private plan. The existing one-shot current review uses the same path and preserves
its original profile, preparation and execution failure causes.

`planLogicalReview` retains that admission beside the original complete logical owner.
`logicalReviewPlanInfo` exposes copied work/coverage; `logicalReviewPlanSource` retains original
logical provenance. Failed admission retains its actual current preparation reason and no usable
plan. `executeLogicalReview` accepts no replacement inventory, rates or limits and returns the
existing original-current reviewed logical pair. Content failure leaves the same immutable plan
available for a later retry. Default plans refuse explicitly.
