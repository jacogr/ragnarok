# Supplied inventory on current successors

Scope: read-only state qualification after the authenticated current candidate has produced
`PreparedCurrentChainUpdate`. Pins remain Gray Paper `1fa8cbc7e7ec3e60d09f8e704911a89c6837ce1d`
and vectors `d3c089c9a1d5352ad353626d7a2db8589f137b2a`.

`qualifyCurrentState` accepts only `CurrentGlobalSerialization`, stable borrowed explicit service
declarations and explicit inventory limits. Exact complete manifest matching precedes compact fact
capture, preserving both genuinely failed nested stages. Success retains the original qualified
update/profile and inventory matched to the original snapshot identity. It accepts no replacement
map or profile. Capture revalidates using the existing bounded inventory implementation; mandatory
matching hashes are included, and no cached/trusted matching shortcut is introduced.

Supplied declarations are checked, not producer-exported. Raw storage keys are not retained by
compact `StateInventory`. This does not establish producer-owned complete logical parent inventory,
code availability, whole-state semantic validity, STF parity, root trust, installation or finality.
C15/C16 completion remains state processing rather than chain finalization. Resource refusal never
means successful empty inventory. Private defaults/results preserve guarded extraction and distinct
manifest/mapping/opaque/codec/fact admission reasons.

Use synchronously at the documented stable host boundary before proof enqueue or after collection
or joined shutdown. Copies, aliases and retirement share canonical state ARC ownership; cancellation
and worker completion alone do not release the worker lease. No worker, Services, RPC, storage API,
format, producer or adoption changes are made.

Verification: signed ordinary, disputed, ticketed and epoch complete authored successors; exact owner
identity; mutated, missing and duplicate declarations; cached manifest and fact limits; preserved
legacy sentinel mismatch; detached fixed metadata; hash-free queries; 1,000-cycle ARC retirement;
strict runtime/default/reason guards and compiler privacy/nominal rejection with signed positive control.
