# Collected logical independent resource ledgers

The native resource-ledgers suite admits exact actual complete-map entry/node/value/service limits,
compact fact/descriptor limits and additional retained raw-key counts/bytes/descriptors. Eleven
one-short policies refuse at their original complete-current or extra logical stage. Policies are
frozen on the actual receipt/target. Maximum-u64 policies still allocate only actual bounded source
shapes and preserve unchanged descriptor accounting. No capacity value becomes native cardinality,
complete empty state or a substitute root/profile. Source and caller arrays remain unchanged.
