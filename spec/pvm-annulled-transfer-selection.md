# Outgoing transfer projection after conflict annulment

Authority: Gray Paper `1fa8cbc7e7ec3e60d09f8e704911a89c6837ce1d`,
eq:accpar `acc(s)`, `N(o)` and ordered concatenation of selected outgoing transfers.
A genuine annulment certificate supplies all original producers and the selected
outgoing counts. Collect producers in numeric service order and preserve each
surviving producer's exact append order, duplicates and fixed memo values.

Canceled producers contribute no outgoing values or paid-gas refund, but remain
in the original-source collection for actual-gas accounting and original provision
provenance. Retain the exact conflict certificate; an ordinary explicit-order
collection has a typed NoAnnulment observation. Keep that existing API's ordering,
duplicate-source semantics and resource policy unchanged.

Bound all producers before sorting/capture; only selected outgoing values consume
transfer/memo limits. Never traverse a canceled original's transfer array. Checked
fixed extents precede allocation and multiplication. Default selection, insufficient
source/value/memo policy, default extraction and wrong nominal units refuse without
partial ownership. Test real canceled/surviving producers, numeric source ordering,
pending-budget actual usage versus refund, immutable ownership and ARC release.
This layer does not claim yield/global/physical-write integration or enable foreign
account publication.
