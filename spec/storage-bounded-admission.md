# Bounded encoded-record admission

This feature tranche starts at merged `d5064139a6775faf2b82c53d941522ab7d65ae31`. The prior
[read-memory qualification](storage-read-memory-qualification.md) reduced transient copies but
retained a complete decoded transport batch alongside immutable repository cells. Refresh actual
allocation/lifetime evidence on this pipeline before attributing its remaining peak or selecting
retained-node layout changes. Keep compiler/providers, checked ARC/Clang release/LTO, physical
formats, existing error precedence, strict complete graph admission and default Perf workloads fixed.

The intended increment preflights all serialized extents, budgets, canonical fields and duplicate
addresses before record delivery. Decode and hash one detached record at a time into private staged
repository cells. Borrowed input stays stable throughout the synchronous operation; success retains
no borrow. A streaming delivery callback may observe a validated prefix before later integrity or
consumer refusal: delivery itself grants no complete-graph or transaction authority. Repository
admission must stage privately and publish only after all integrity, ordering, reachability,
root/count, inventory and inherited-policy checks succeed. Existing mutable raw APIs keep their
copy/validation contracts. No public validation bypass flag or caller-authored trusted token.

Completion checks cover malformed/truncated/overflowing extents, duplicate/order and late hash
failures, zero-delivery structural preflight refusal, consumer refusal, empty and large payloads,
mutable source independence, stale/base/conflict precedence, multi-root/orphan rejection and
unchanged selected-file bytes. Run selected native Make suites and affected consumers. Measure the
unchanged fresh-reopen workload before/after in reversed binary orders and qualify relevant Linux
pressure independently. Treat completed reopens, observer timeouts and local OOM outcomes separately.
This does not promise a 128 MiB no-swap deployment, recoverable allocation failure or out-of-core
storage, and adds no M1 or full protocol state-serialization completion claim.
