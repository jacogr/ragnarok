# Host configured logical seed

`captureLogicalSeed` composes existing selected-parent profile/global/logical qualification on the
actual application chain. The Services overload enforces preparation, proof and publication
exclusion before canonical access. Borrowed declarations remain stable during the call; retained
raw keys are detached. Independent profile, global and logical budgets and original typed failures
remain visible. Missing head/C9, malformed values, missing complete declarations and resource
refusals never grant a prefix. No producer manifest, root trust, finality or installation is added.

The application_logical_seed native suite checks actual reparsed Services ownership, caller key
mutation, all admission stages and absent chain selection. Existing pinned current-schema codecs
and full/light separation apply unchanged.
