# M1 codec progress

Target: Gray Paper 0.8.0 and published `davxy/jam-test-vectors` v0.8.0, at the exact revisions in
`spec/pins.json`. The **C.1/C.2 framing baseline is implemented within the schema scope below**.
This is not complete state serialization or a production-client milestone. Published codec samples
are syntactic fixtures; this project also enforces the documented canonical/structural policies,
without claiming complete state-transition or cryptographic eligibility from decoded values.

The maintainer wants manageable chunks of related functionality. Complete a coherent group,
report tested results, then wait for the next go-ahead. Do not equate one passing sample or one
round-trip with completion of a codec family.

## Scope boundary and next decision

The concrete C.2 gaps identified in the [coverage audit](codec-coverage.md) are now covered.
General collections support the explicitly documented value-only scalar families; arbitrary child
schemas need explicit adapters and ownership contracts. State/Merkle layout, PVM execution and
full state transitions remain separate work. The next scope requires a maintainer go-ahead.
Linux CI still needs to confirm each pushed increment; local passing tests are not a CI result.

Each group needs strongly typed sources, failure-only results, explicit ownership/lifetimes,
atomic output where applicable, published JSON-to-wire agreement, independent field observation,
boundary/malformed/alias tests, appropriate nominal rejections and Linux CI wiring. Keep all
runtime guards in optimized ARC/Clang LTO checks. Correctness work does not reopen language
selection or introduce performance targets.

Current ticket/guarantee validation: 22,939 ticket requests, 7,617 guarantee requests, native
ownership/atomicity/alias regressions, five nominal rejection probes and one private-owner probe.
These are deterministic test workload counts, not historical development or reliability metrics.

probes and one private-owner probe, plus native ownership/atomicity/alias checks. Both original
published samples are expected canonical-order rejections; sorted derived counterparts pass.
