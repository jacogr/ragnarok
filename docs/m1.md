# M1 codec progress

Target: Gray Paper 0.8.0 and published `davxy/jam-test-vectors` v0.8.0, at the exact revisions in
`spec/pins.json`. M1 is **in progress**. Published codec samples are syntactic fixtures; this project
also enforces the explicitly documented canonical/structural policies, without claiming complete
state-transition or cryptographic eligibility from decoded values.

The maintainer wants manageable chunks of related functionality. Complete a coherent group,
report tested results, then wait for the next go-ahead. Do not equate one passing sample or one
round-trip with completion of a codec family.

## Suggested next groups

1. **Disputes**: one coherent family with bounded verdict/vote/offense structures, fixed Boolean
   tags, canonical ordering and the published 0.8.0 vectors. Keep contextual judgment/signature
   validation separate from framing and structural policy.
2. **Work-package inputs**: standalone refinement context, tagged import reference, extrinsic
   commitments, work item and package. Share scalar/context definitions where doing so reduces
   duplicated protocol rules without changing established report behavior.
3. **Headers and markers**: include 0.8.0 variable validator sequences and E1 winning attempts.
4. **Block composition and coverage audit**: complete extrinsic/block vectors, all truncation and
   late-failure paths, then explicitly inventory any remaining C.1/C.2 terms. State Merkle layout,
   PVM execution and full state transitions remain separate work.

Each group needs strongly typed sources, failure-only results, explicit ownership/lifetimes,
atomic output where applicable, published JSON-to-wire agreement, independent field observation,
boundary/malformed/alias tests, appropriate nominal rejections and Linux CI wiring. Keep all
runtime guards in optimized ARC/Clang LTO checks. Correctness work does not reopen language
selection or introduce performance targets.

Current ticket/guarantee validation: 22,939 ticket requests, 7,617 guarantee requests, native
ownership/atomicity/alias regressions, five nominal rejection probes and one private-owner probe.
These are deterministic test workload counts, not historical development or reliability metrics.
